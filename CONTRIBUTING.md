# Contributing to Gemini Chat Assistant

Thank you for contributing to **Gemini Chat Assistant**!

## Development Guidelines
1. **Branching Strategy:** Work on feature branches corresponding to the current roadmap node (e.g. `feat/n1-scaffold`).
2. **Coding Standards:** Follow WordPress Coding Standards (WPCS) and strict typing in PHP 8.0+.
3. **Commit Messages:** Follow the Conventional Commits specification (e.g., `feat(rest): add health check controller`).
4. **Testing:** All pull requests must pass `composer test`, `composer lint`, and `composer phpstan`.
5. **Zero Secrets:** Never commit real API keys, credentials, or private keys to the repository.
